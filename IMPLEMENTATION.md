# Implementation steps

1. **Request intake (implemented):** Parse exactly one matter number and one of the five supported categories from an email. Return a clarification for missing or ambiguous requests. Keep quoted prior replies out of scope.
2. **Browser retrieval (implemented and verified for one matter):** `scripts/retrieve-uarb.mjs` searches a matter, reads five tab counts, and downloads up to ten files from the selected category. It handles FileMaker's editable matter field and filename confirmation dialog. The live site labeled the fifth tab Recordings, while the adapter also accepts Audio Files. It skips zero-count tabs and restarts the matter after paged counting so selection begins on the first page.
3. **Core retrieval (implemented locally):** `senpilot/uarb.py` runs the browser script and checks the matter, category, counts, row count, and downloaded file paths before passing the result to the worker. `senpilot/archive.py` applies basic file checks and creates the ZIP.
4. **Email workflow (implemented locally):** `senpilot/mail.py` fetches unseen requests over IMAP and sends replies over SMTP/TLS. `senpilot/worker.py` connects intake, UARB retrieval, ZIP creation, reply composition, and sending. It sends a factual failure reply if retrieval cannot complete. `python3 -m senpilot.run` polls the mailbox every 60 seconds; `--once` processes currently unseen mail and exits. No live mailbox or UARB run has been completed.
5. **Remaining acceptance:** Verify a partial download failure and the complete email send/receive flow after mailbox configuration. Bounded retries and structured logs remain production extensions.

The UARB endpoint is reachable through a North American VPN. On 2026-09-20, a live run for `M00001` / Other Documents returned all five category counts, matter metadata, two document records, and two nonempty PDF downloads. A run for `M00001` / Key Documents returned the expected zero count and no files. A run for `M12205` / Other Documents found 43 records and downloaded ten PDF files, including two reached by scrolling the virtual document grid. The Python bridge then created a ten-file ZIP and composed a reply with one attachment, without sending email. A nonexistent `M99999` produced an explicit no-records failure. The site intermittently returned empty network responses during testing, so live runs may need another attempt.

Run all local tests with `python3 -m unittest discover -s tests -v`. When the site is reachable, run `npm run probe:uarb` to capture the entry page text and screenshot before implementing browser locators. The probe reports the last browser URL and attempts a diagnostic screenshot on failure. Set `UARB_TIMEOUT_MS=60000` to allow a slower connection more time.

Run the browser proof of concept with `npm run inspect:uarb -- M12205 'Other Documents'`. It writes up to ten downloaded files under `artifacts/M12205/` and prints a JSON result. Further live acceptance cases are listed above.

The earlier SQLite job ledger, ZIP manifest/hash data, and offline fixture harness were removed to keep the assessment implementation focused on the requested behavior. `DESIGN.md` still describes those as possible production extensions, not implemented features.

For a provider that supports IMAP and SMTP with password authentication, create a dedicated IMAP folder for requests. Set `SENPILOT_IMAP_FOLDER` to that folder's name, plus `SENPILOT_IMAP_HOST`, `SENPILOT_SMTP_HOST`, `SENPILOT_EMAIL_USER`, `SENPILOT_EMAIL_PASSWORD`, and `SENPILOT_AGENT_ADDRESS`. The adapter refuses `INBOX` to prevent replies to unrelated personal mail. Ports default to 993 and 465, with optional `SENPILOT_IMAP_PORT` and `SENPILOT_SMTP_PORT`. Credentials are read when constructing the adapters and are not stored in this repository. After the browser selectors and mailbox settings have been verified, run `python3 -m senpilot.run --once` for a single folder pass or `python3 -m senpilot.run --poll-seconds 60` for continuous polling. The polling process stops on an unexpected error so an uncertain send is not retried automatically.
